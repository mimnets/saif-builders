# অ্যাডমিন গাইড: ওয়েবসাইটের লেখা ও ছবি বদলানো

অ্যাডমিন প্যানেল: **https://www.saifbuildersbd.com/admin/**

কোনো আলাদা সার্ভার বা ডাটাবেস নেই। আপনি যা বদলাবেন, তা সরাসরি GitHub-এ সেভ হয়, আর ১–২ মিনিট পর ওয়েবসাইটে দেখা যায়।

---

## ১. লগইন

প্রত্যেক এডিটরের একটা GitHub অ্যাকাউন্ট লাগবে, আর রিপোতে **Write** অনুমতি থাকতে হবে
(রিপোর মালিক: Settings → Collaborators → Add people)।

- **Sign in with GitHub** বাটন (নিচের "লগইন সেটআপ" একবার করা থাকলে), অথবা
- **Sign in with Token**: GitHub → Settings → Developer settings → Fine-grained token →
  শুধু `mimnets/saif-builders` রিপো, **Contents: Read and write** → টোকেনটা পেস্ট করুন।

## ২. কোথায় কী বদলাবেন

| কী বদলাতে চান | অ্যাডমিনে কোথায় |
|---|---|
| ফোন, হোয়াটসঅ্যাপ, ঠিকানা, ফেসবুক | সাইট সেটিংস → যোগাযোগ ও সাধারণ তথ্য |
| **লোগো** | সাইট সেটিংস → যোগাযোগ ও সাধারণ তথ্য → লোগো (ফুটার) আর লোগো আইকন (হেডার) |
| প্রথম স্ক্রিনের লেখা, স্লাইডের ছবি, সংখ্যার ঘর | সাইট সেটিংস → হোম পেজ → হিরো |
| সুবিধা, ধাপ, এলাকা, রিভিউ, প্রশ্নোত্তর | সাইট সেটিংস → হোম পেজ → (সেকশন) |

| "আসন্ন প্রজেক্ট" পেজের লেখা | সাইট সেটিংস → আসন্ন প্রজেক্ট (পেজ) |
| **রঙের থিম** (কার্ডের রঙ, সোনালির শেড, ফুটার) | সাইট সেটিংস → যোগাযোগ ও সাধারণ তথ্য → রঙের থিম |

বদল করে উপরে **Save / Publish** চাপুন।

## ৩. ছবি

- ছবির ঘরে ক্লিক করে কম্পিউটার বা মোবাইল থেকে আপলোড করুন। বড় ছবি নিজে থেকেই ছোট (WebP) হয়ে যায়।
- প্রজেক্টের ছবি ফাইলে যায় `public/uploads/projects/` ফোল্ডারে, বাকি ছবি `public/uploads/` এ।
- **প্রধান ছবি**: ১৬:১০ বা ১৬:৯ অনুপাতের আড়াআড়ি ছবি, অন্তত ১৬০০ পিক্সেল চওড়া।
- **ফ্লোর প্ল্যান**: সাদা ব্যাকগ্রাউন্ডের পরিষ্কার ছবি, PNG/JPG/SVG।
- **লোগো**: বর্গাকার, SVG হলে সবচেয়ে ভালো, নাহলে অন্তত ৫১২×৫১২ PNG।
- **শেয়ার ইমেজ** (ফেসবুকে লিংক দিলে যে ছবি দেখায়): ১২০০×৬৩০।

## ৪. লেখার নিয়ম

- সংখ্যা বাংলায় লিখুন (১০০০, ৩৫ লাখ)। শুধু **ফোন নম্বর, ফ্লোর প্ল্যানের সাইজ আর ক্যালকুলেটরের টাকা** ইংরেজি সংখ্যায়, কারণ সেগুলো দিয়ে হিসাব হয়।
- ছোট বাক্য, এক অনুচ্ছেদে ২–৩ বাক্য। মোবাইলে পড়তে সহজ হয়।

## লগইন সেটআপ ("Sign in with GitHub" বাটনের জন্য, একবার করলেই হবে)

স্ট্যাটিক সাইট নিজে GitHub লগইন সামলাতে পারে না, তাই একটা ছোট ফ্রি Cloudflare Worker লাগে:

1. https://github.com/sveltia/sveltia-cms-auth এ গিয়ে **Deploy to Cloudflare Workers** চাপুন (ফ্রি অ্যাকাউন্ট)।
   Worker-এর URL পাবেন, যেমন `https://sveltia-cms-auth.<নাম>.workers.dev`।
2. GitHub → Settings → Developer settings → **OAuth Apps → New OAuth App**
   - Homepage URL: `https://www.saifbuildersbd.com/`
   - Authorization callback URL: `https://sveltia-cms-auth.<নাম>.workers.dev/callback`
   - Client ID আর একটা Client Secret তৈরি করে রাখুন।
3. Cloudflare → Worker → Settings → Variables:
   `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` (Secret হিসেবে), `ALLOWED_DOMAINS` = `www.saifbuildersbd.com, saifbuildersbd.com`
4. `public/admin/config.yml` এ `base_url:` লাইনের `#` সরিয়ে Worker-এর URL বসান।
